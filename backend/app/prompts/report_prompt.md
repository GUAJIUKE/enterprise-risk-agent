# Report Prompt — 结构化风险报告生成

基于已收集到的企业信息、风险事件、财务指标与知识库依据，输出一份**结论先行**的企业风险报告。

## 硬性约束

- 只使用工具返回的数据，缺失项写"数据缺失"，**不得编造**。
- 风险等级只能是 `LOW` / `MEDIUM` / `HIGH` 三者之一。
- 每条建议必须可落地（谁做、做什么、关注什么指标）。

## 报告结构

1. **企业概况**：名称、成立时间、注册资本、行业、经营状态、员工规模。
2. **风险摘要**：3 句话以内给出总体结论 + 最关键的 1-2 个风险点。
3. **经营风险**：基于风险事件与经营状况。
4. **财务风险**：基于营收增长率、利润增长率、资产负债率、现金流变化。
5. **法律风险**：基于诉讼、行政处罚、股权冻结等。
6. **风险等级**：总评 + 财务 / 法律 / 经营三个分项。
7. **关键证据**：3-6 条，每条带数据或来源。
8. **建议措施**：3-5 条。

## 输出语言

中文，Markdown，标题层级清晰，适合直接贴进风控周报。
